# Принтеры — дашборд

Доступность принтеров по SNMP, расходники, крышки, простои за сутки. 12
панелей, шесть строк, две из них свёрнуты.

[[Главная]] · [[Дашборды]] · [[MikoPBX]] · [[Принтеры]] · [[CCTV]]

---

## Параметры

| | |
|---|---|
| uid | `aprj7f` |
| Папка | Принтеры алерты (`fg176bwdmcetca`) |
| Панелей | 12 — 5 table, 4 stat, 1 alertlist, 1 barchart, 1 status-history |
| Строк | 6, из них 2 свёрнуты |
| Период по умолчанию | 24 часа |
| Задача Prometheus | `printers_snmp` |
| Открыть | `http://192.168.2.50:3001/d/aprj7f` |

## Переменные

| Переменная | Тип | Значения |
|---|---|---|
| `loc` | custom | СПБ Инженерная 15 `[12]` · Краснодар `50` · МСК Лианозово `77` · МСК Лыткарино `177` |
| `prt` | query | имена принтеров внутри выбранной локации |

`loc` — жёстко зашитый список из четырёх значений. Новую площадку в неё
добавить нельзя, пока не поправить саму переменную в настройках дашборда.

## Что в каждой строке

### Сводка — 5

`Всего принтеров` · `В сети` · `Низкий тонер` · `Крышка открыта` ·
`Активные проблемы (алерты)`

### Статусы и аптайм — 0

> [!warning] Пустая строка
> Строка есть, панелей внутри нет. Скорее всего панели убрали или перенесли
> в другие строки — на дашборде они остались как разделитель. Разбирается
> только вручную.

### Главная — 1

`Все принтеры` — таблица со всеми принтерами выбранной локации

### Допольнительное — 3

`Аптайм за 24 ч (худшие сверху)` · `Простои за 24 ч (минут)` ·
`Пульс-сетка` (`status-history`)

### Уровень тонера — 1, свёрнута

`Уровень тонера (худшие сверху)` — расходники по всем картриджам

### Ошибки и крышка — 2, свёрнута

`Ошибки за 24 ч (замятие, шум, тонер)` · `Крышка открыта (сейчас)`

> [!note] Свёрнутые строки не грузятся
> Пока строка закрыта, её панели не запрашивают данные. Пустая свёрнутая
> строка — не значит, что данных нет.

## Смотреть первым делом

1. **`В сети`** против `Всего принтеров` — расхождение это и есть down.
2. **`Активные проблемы (алерты)`** — четыре правила по принтерам живут в
   [[grafana-alerts-current]].
3. **`Уровень тонера`** — раскрыть строку, отсортировано по худшим.

## Особенности

> [!warning] Панель алертов будет пустой
> Ни одно из четырёх правил по принтерам не привязано к дашборду
> (`dashboardUid` пуст), поэтому `alertlist` их не покажет. Уведомления в
> Битрикс24 при этом доходят. Подробнее: [[Дашборды]].

> [!warning] Метрика недоступности — `up`, а не `probe_success`
> Принтеры опрашиваются по SNMP, поэтому работает `up{job="printers_snmp"}`.
> Ловушка `probe_success == 0` относится только к камерам на [[CCTV]].

> [!info] Три принтера были недоступны на 16.10.2026
> Число может отличаться — проверяй по панели, а не по этому документу.
