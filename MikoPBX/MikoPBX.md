# MikoPBX — дашборд АТС

Самый большой дашборд стенда: 48 панелей, вся телефонная станция — состояние
Asterisk, SIP-пиры, звонки, ресурсы, транки и сам экспортёр.

## Параметры

| | |
|---|---|
| uid | `mikopbx-pbx` |
| Папка | Телефония (`telephony`) |
| Панелей | 48 — 26 stat, 11 bargauge, 6 timeseries, 5 gauge |
| Строк | 5 |
| Период по умолчанию | 6 часов |
| Переменных | нет |
| Теги | `pbx`, `телефония`, `mikopbx`, `мониторинг` |
| Задача Prometheus | `mikopbx`, интервал 60 с |
| Открыть | `http://192.168.2.50:3001/d/mikopbx-pbx` |

Все панели лежат внутри строк, наружу не вынесены ни одной.

## Что в каждой строке

### Состояние станции — 5

`Asterisk` (`mikopbx_asterisk_up`) · `Экспортёр` (`up{job="mikopbx"}`) ·
`Аптайм Asterisk` · `Простой с перезагрузки` · `Время скрапа`

Первые две — единственные панели дашборда, которые показывают, жив ли
мониторинг вообще. Остальные — context.

### Телефония — 13

`SIP-пиры онлайн` · `SIP-пиров всего` · `Доля онлайн` · `Активные звонки` ·
`Каналов активно` · `Звонков обработано` · `Транков поднято` ·
`Транков отключено` · `Транки по состояниям` · `Звонки с рестарта Asterisk` ·
`Активные звонки по направлениям` · `SIP-пиры по состояниям` ·
`Доля SIP-пиров в сети`

### Ресурсы станции — 13

`CPU` · `Оперативная память` · `Swap` · `Место на /offload` · `Процессов` ·
`Аптайм системы` · `Load average` · `Заполнение файловых систем` ·
`Трафик eth0` · `Заполнение inode` · `Ошибки сети по интерфейсам` ·
`Потоков в системе` · `Свободных дескрипторов`

### Транки — 4

`Регистрация транков` · `Отвечено звонков за сутки` · `Средний биллинг по
транкам` · `Звонки за час по транкам`

Все четыре читают кэш, который наполняет cron раз в 5 минут. Пустые bargauge
чаще всего означают не «нет звонков», а незаполненный кэш.

### Экспортёр — 13

`Сборщики поимённо` · `Память экспортёра` · `Свободно на файловых системах` ·
`Аптайм станции, суток` · `Asterisk, версия` · `Худший сборщик` ·
`Длительность сборщиков` · `Дескрипторов открыто` · `Бюджет скрапа, с` ·
`GC запусков у экспортёра` · `Готовность сборщиков` ·
`Возраст кэша статистики` · `Транков зарегистрировано`

## Смотреть первым делом

1. **`Экспортёр`** — если 0, метрики ниже устарели, весь остаток дашборда
   врёт. Панель «нет данных» внизу означает то же самое.
2. **`Худший сборщик`** и `Сборщики поимённо` — 0 означает, что часть
   метрик не обновляется, причём молча.
3. **`Возраст кэша статистики`** — больше 600 секунд означает, что cron
   отвалился, и вся строка «Транки» замерла.
4. **`Свободных дескрипторов`** — ноль означает, что станция не примет новых
   соединений.
5. **`Заполнение inode`** — 1.0 при свободных байтах означает, что кончились
   не байты, а inode.

## Особенности

> [!warning] CPU считается не как в документации модуля
> Панель `CPU` использует
> `sum(rate(mikopbx_system_cpu_seconds_total{mode!="idle", cpu!="all"}[5m])) / 100 / count(count by (cpu) (...))`
> Обязателен фильтр `cpu!="all"`: эта серия равна **сумме** ядер, а не
> среднему, и без фильтра загрузка завышается вдвое.

> [!warning] Дашборд ломается при обновлении экспортёра
> За один день 19.10.2026 модуль обновляли **четыре** раза. Три первых сломали
> часть панелей — они молча показывали «нет данных». Четвёртое, 1.3.0 → 1.3.1,
> прошло чисто: все 48 панелей живы.
>
> Признак поломки — пропавшие панели, а не ошибка на странице. Проверять:
> ```bash
> curl -s http://192.168.2.77:9713/metrics | grep -c '^# HELP mikopbx_'
> ```
> Разбор по версиям: [[mikopbx-exporter]].

> [!info] Пять метрик появились, но панелей на них нет
> В 1.3.1 вернулись и появились `kernel_oom_kills_total`,
> `kernel_panics_total`, `modules_total`, `modules_enabled` и `build_info`.
> Ни одна панель их не использует — дашборд про обновление ещё не знает.
> Самое ценное из этого — OOM-киллы и паники ядра, их раньше было видно
> только на консоли АТС.

> [!info] На дашборд нет ни одного правила алерта
> Падение экспортёра, падение Asterisk, нулевая регистрация транков —
> ни одно из этого не вызовет уведомление. Правила живут в
> [[grafana-alerts-current]].

> [!note] Актуальность состояния
> Снято 19.10.2026 сразу после обновления до 1.3.1: `Asterisk` = 1,
> `Экспортёр` = 1, `Худший сборщик` = **1** (починен), SIP-пиров 104,
> онлайн 0, транков отключено 8 из 8, зарегистрировано 0, звонков
> обработано 9, активных 0, возраст кэша статистики 90–125 с.
>
> Две тревожные цифры не изменились: inode = 1.0 на двух ФС, свободных
> дескрипторов **0** при 1216 открытых. Цифры меняются — перепроверяй.
